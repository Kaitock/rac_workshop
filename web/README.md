# ผู้ช่วยระเบียบนาวา · หน้าเว็บแชต

หน้าแชตถามระเบียบบริษัทที่ค้นในเบราว์เซอร์ทั้งหมด ไม่ใช้ AI และไม่ส่งคำถามออกจากเครื่อง
คำตอบเป็นข้อความที่คัดจากเอกสารพร้อม chunk_id

- เปิด `web/index.html` ในเบราว์เซอร์ได้เลย
- เวอร์ชันที่เผยแพร่: https://claude.ai/artifact/4koHXjnjcGDqCHiJhcWjMT
- แบบร่าง UX/UI (หน้าพนักงานและหน้าผู้ดูแล ทั้งเดสก์ท็อปและมือถือ): https://claude.ai/artifact/WXShNayQtM24zyvyMsD9YP

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `engine.js` | ตัวค้นแบบเดียวกับ `rag/retrieve.py`: TF-IDF ตัวอักษร (char_wb 2–4) + BM25 บนคำที่ตัดด้วย `Intl.Segmenter` น้ำหนัก 0.5/0.5 |
| `template.html` | หน้าตา (โทนแดง-ทอง) และตรรกะของแชต |
| `build.py` | รวม template + engine + chunk จาก `data/docs` และคำพ้องจาก `rag/retrieve.py` เป็น `index.html` |
| `index.html` | ไฟล์ที่สร้างแล้ว พร้อมเปิดใช้ |

แก้เอกสาร คำพ้อง หรือ template แล้วสร้างใหม่ด้วย

```bash
python3 -m web.build              # หน้าเว็บเปิดในเบราว์เซอร์ได้เลย
python3 -m web.build --fragment   # เฉพาะเนื้อหาหน้า สำหรับเผยแพร่เป็น artifact
```

## กติกาที่หน้าเว็บทำตาม

- ค้นเฉพาะฉบับ active ถ้าเรื่องนั้นมีฉบับเดิมจะแจ้งว่าระเบียบเปลี่ยนพร้อมวันที่มีผล โดยไม่ยกตัวเลขเก่า
- คำตอบ: ไม่เกิน 2 บรรทัดจาก chunk อันดับ 1 และอีก 1 บรรทัดจาก chunk ถัดไปที่มีคำในคำถามเกือบครบ
- ถ้าไม่มีคำไหนในคำถามตรงกับคำในเอกสาร ตอบว่าเรื่องนี้ไม่อยู่ในเอกสาร
- ถ้าคำตรงกันน้อย (ต่ำกว่า 34% หรือคะแนนต่ำกว่า 0.2 และคำตรงไม่ถึง 60%) เตือนว่าไม่พบข้อความที่ตรงชัดเจน
- ซ่อนบรรทัดในเอกสารที่สั่งให้ระบบ AI เปลี่ยนวิธีตอบ
